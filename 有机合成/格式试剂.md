# 格氏试剂反应方法总结（操作流程版）

## 1. 试剂与仪器准备

### 常用试剂
- 格氏试剂（RMgX，市售溶液或现制）
- 有机锂试剂（RLi，如 MeLi、n-BuLi、PhLi，作为高活性替代）
- 无水溶剂：四氢呋喃（THF）、乙醚（Et₂O）、2-甲基四氢呋喃（2-MeTHF）等
- 淬灭剂：饱和氯化铵水溶液、稀盐酸、水
- 干燥剂：无水硫酸钠（Na₂SO₄）或无水硫酸镁（MgSO₄）

### 仪器与装置
- 干燥三口瓶（或 Schlenk 瓶）、恒压滴液漏斗、磁力搅拌子
- 低温浴：冰水浴（0 ℃）、干冰/丙酮浴（-78 ℃）等
- 惰性气体保护：高纯氮气或氩气，Schlenk 双排管或气球保护
- 分液漏斗、旋转蒸发仪、色谱柱等后处理设备

## 2. 单加成反应操作步骤（约 1:1 化学计量）

### 适用底物
醛、酮、Weinreb 酰胺、腈（水解得酮）、CO₂ 等。

### 2.1 使用格氏试剂（RMgX）

#### 反应准备
1. 将干燥的三口瓶、搅拌子、恒压滴液漏斗安装好，接氮气/氩气保护。
2. 向三口瓶中加入底物（1.0 equiv），加入无水 THF（约 5–10 mL/mmol 底物），搅拌至完全溶解。
3. 体系用氮气/氩气置换三次，保持惰性气氛。

#### 低温滴加
4. 将三口瓶置于冰水浴中，冷却至 0 ℃（或根据底物活性选择 -78 ℃ 等更低温度）。
5. 用注射器或恒压滴液漏斗缓慢滴加格氏试剂（1.05–1.3 equiv），控制滴加速度，使体系内温基本稳定，避免温度剧烈升高。

#### 反应与监测
6. 滴加完毕后，撤去冷浴，自然升温至室温（20–25 ℃），继续搅拌 1–4 小时。
7. 反应监测：取少量反应液，加入饱和 NH₄Cl 水溶液淬灭，取有机相进行 TLC 或 GC 分析。

#### 后处理
8. 反应完成后，将反应液冷却至 0 ℃，在搅拌下**缓慢滴加**饱和 NH₄Cl 水溶液淬灭，直至无气泡产生。
9. 将混合液转移至分液漏斗，分液。水相用乙酸乙酯（或乙醚）萃取 2–3 次。
10. 合并有机相，用饱和食盐水洗涤一次，加入无水 Na₂SO₄ 或 MgSO₄ 干燥至少 30 分钟。
11. 过滤，减压浓缩除去溶剂，粗产物经柱层析或重结晶纯化。

### 2.2 使用有机锂试剂（RLi）

#### 操作要点
- 将底物溶于无水 THF，氮气/氩气保护下冷却至 -78 ℃（干冰/丙酮浴）。
- 缓慢滴加有机锂试剂（1.05–1.3 equiv），保持低温。
- 滴毕后，保持 -78 ℃ 搅拌 0.5–2 小时，然后缓慢升至室温。
- 后处理与格氏试剂相同，淬灭时需保持低温。

#### 特别注意
- 有机锂试剂对空气和湿气极度敏感，所有操作应在严格无水无氧条件下进行，建议使用 Schlenk 技术或手套箱。
- 淬灭时放热更剧烈，务必缓慢滴加淬灭剂，防止喷溅。

## 3. 过量加成反应操作步骤（通常 2–5 当量）

### 适用底物
酯、内酯、酰氯、酸酐、酰胺等羧酸衍生物，生成叔醇或双加成产物。

### 3.1 一锅法

#### 操作步骤
1. 将底物（1.0 equiv）加入干燥三口瓶，溶于无水 THF（8–15 mL/mmol），氮气/氩气保护。
2. 在冰水浴冷却下，通过恒压滴液漏斗缓慢滴加格氏试剂（3.0–5.0 equiv，常用 3–4 equiv），控制滴速。
3. 滴加完毕后，撤去冷浴，升温至室温或回流（THF 回流约 66 ℃），继续搅拌 4–12 小时，必要时回流过夜。
4. 反应监测：取样淬灭后 TLC/GC 确认原料消失。
5. 后处理：将反应液冷却至 0 ℃，**极其缓慢**地滴加饱和 NH₄Cl 水溶液或稀盐酸淬灭，强烈搅拌。若有大量镁盐沉淀，可加入稀酸溶解或硅藻土过滤。
6. 后续萃取、洗涤、干燥、浓缩、纯化同单加成操作。

#### 添加剂（可选）
- 可加入 CuI（0.1 equiv）或 LiCl 促进反应或提高选择性。
- 对共轭体系需注意区分 1,2- 与 1,4-加成产物。

### 3.2 两步法（可控）

#### 操作步骤
1. **第一步**：将底物溶于无水 THF，氮气保护下冷却至 -78 ℃ 至 0 ℃，缓慢滴加 1.0–1.2 equiv 格氏试剂，搅拌反应生成酮中间体。
2. **第二步**：将反应液升温至室温或回流，补加格氏试剂至总当量 2.5–3.5，继续搅拌至反应完全。
3. 后处理同一锅法。

#### 优点
- 可监测中间体酮的生成，适用于选择性要求较高的底物。
- 注意第一步需确认无还原等副反应；对酮中间体不稳定的体系需严格控制温度。

## 4. 关键注意事项

### 4.1 无水无氧要求
- 玻璃仪器需烘箱干燥或火焰烘烤，在氮气/氩气保护下冷却。
- 溶剂必须无水，可使用商品无水溶剂或经钠/二苯甲酮、分子筛干燥。THF 需确保无过氧化物。
- 反应全程保持惰性气体正压。

### 4.2 格氏试剂的制备与使用
- 制备格氏试剂时，镁屑与卤代烃在引发条件下反应。常用引发方法：少量碘、1,2-二溴乙烷（有致癌性，慎用）、超声或机械摩擦。
- 使用前可用 2-丁醇/1,10-菲咯啉滴定法标定浓度。
- 市售格氏试剂密封、阴凉保存；现制试剂应尽快使用。

### 4.3 底物兼容性
- 含活泼氢的官能团（–OH、–NH、–SH、–C≡CH、–COOH 等）必须预先保护，否则会消耗格氏试剂并产生烷烃。
- 若只希望单加成，应选择醛、酮或 Weinreb 酰胺作为底物；酯类通常继续加成至叔醇。
- 环氧、硝基等官能团可能与格氏试剂反应，需避免或采用保护策略。
- 卤素（Cl、Br、I）与格氏试剂可能发生交换或偶联，与有机锂试剂更易发生卤素-金属交换，设计反应时需注意。

### 4.4 反应监测
- 格氏试剂体系偏碱性，直接 TLC 可能拖尾或分解；建议取少量反应液，加入饱和 NH₄Cl 淬灭后取有机相点板。
- 可配合 GC/MS 或 HPLC 监测反应进程。

### 4.5 后处理要点
- **淬灭**：务必**低温、慢滴、搅拌**。若反应规模较大或放热剧烈，可将反应液通过滴液漏斗缓慢转移至冰淬灭剂中，防止局部过热。
- **破乳**：若出现乳化，可加入饱和 NaCl 水溶液、少量稀酸或硅藻土过滤。
- **干燥**：镁盐会包裹水分，建议干燥时间 ≥ 30 min，必要时过滤后再次干燥。
- **浓缩**：低沸点产物注意减压温度；含 THF 体系可先常压蒸除大部分溶剂，再减压。

## 6. 安全提示

- 格氏试剂和有机锂试剂遇水、空气剧烈反应，可能自燃或释放可燃气体。操作人员必须佩戴护目镜、实验服和阻燃手套。
- 所有操作在通风橱内进行，确保惰性气体保护。
- 淬灭过程产生大量热和可燃气体（如烷烃；若存在未反应金属镁/锂，可能产生氢气），必须在敞开体系中缓慢进行，防止喷溅。
- 有机锂试剂尤其危险，应使用 Schlenk 技术或手套箱操作，并备有干粉灭火器，严禁用水灭火。
