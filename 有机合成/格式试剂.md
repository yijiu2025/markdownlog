# 格氏试剂反应方法总结

## 1. 格氏试剂单加成（1:1 反应）

### 方法A：使用标准格氏试剂（RMgX）
- **投料当量**：底物（醛/酮/酯等） : 格氏试剂 = 1 : 1.1-1.5
- **常用溶剂**：无水四氢呋喃（THF）或乙醚（Et₂O）
- **反应温度**：0°C至室温（20-25°C），或根据底物活性低温滴加
- **反应时间**：1-4小时（滴加完成后）
- **注意事项**：
  - **严格无水无氧**：玻璃仪器需烘干，反应全程需氮气/氩气保护
  - **底物预处理**：底物中不得含有活泼氢（如-OH, -NH₂, -COOH），需预先保护
  - **放热控制**：滴加格氏试剂时控制速度，避免体系温度剧烈升高导致副反应
- **后处理**：
  - 反应完成后，降至0°C，缓慢滴加饱和NH₄Cl溶液或稀HCl淬灭
  - 搅拌直至分层，水相用乙酸乙酯（EA）或乙醚萃取
  - 合并有机相，用盐水洗涤，无水Na₂SO₄或MgSO₄干燥
  - 减压浓缩得粗产物，必要时柱层析纯化

### 方法B：使用有机锂试剂（RLi）
- **投料当量**：底物 : 有机锂试剂 = 1 : 1.1-1.5
- **常用溶剂**：无水THF
- **反应温度**：-78°C（干冰/丙酮浴）至 0°C
- **注意事项**：
  - 反应活性比格氏试剂更高，选择性更好，适合位阻较大的酮
  - 必须在低温下进行，防止烯醇化或过度加成
  - 对空气和湿气极度敏感，操作需使用Schlenk线或手套箱
- **后处理**：
  - 低温下用饱和NH₄Cl溶液淬灭
  - 其余步骤与方法A类似，注意低温萃取

## 2. 格氏试剂过量加成（双加成/过量反应）

### 方法A：两步法/分步控制法
1.  **第一步**：低温下滴加1.0-1.2当量试剂，反应生成中间体（如半缩醛/酮）。
2.  **第二步**：升温至室温或回流，补加试剂（总当量 2.5-3.0）。
    - **投料当量**：底物 : 格氏试剂 = 1 : 2.5-3.0
    - **反应温度**：室温至回流（根据溶剂沸点，如THF 66°C）
    - **注意事项**：
      - 适用于酯类制备叔醇，或反应活性较低底物的完全转化
      - 第一步后可监测中间体生成情况
      - 需确保第一步无副反应（如还原反应）发生

### 方法B：一锅法过量加成
- **投料当量**：底物 : 格氏试剂 = 1 : 3.0-5.0
- **常用溶剂**：无水THF
- **反应温度**：室温至回流
- **反应时间**：4-12小时（通常需回流）
- **注意事项**：
  - 适用于羧酸衍生物（酯、酰胺、腈）的彻底转化
  - 对于位阻大的底物，可能需要更高的温度和更长的时间
  - **催化**：有时加入CuI（0.1eq）或LiCl可促进反应或提高选择性（如1,4-加成）
- **后处理**：
  - 反应液冷却至0°C，**极其缓慢**地加入饱和NH₄Cl溶液（产生大量气体和热量）
  - 若有大量氢氧化镁/氧化镁沉淀，可加入稀酸溶解或硅藻土过滤
  - 萃取、干燥、浓缩后柱层析纯化

## 3. 通用注意事项

### 反应条件优化
- **溶剂选择**：THF最常用；对于醚溶性差的底物可尝试甲苯；低温反应（-78°C）多用THF。
- **引发**：格氏试剂制备时若不引发，可加少量碘或1,2-二溴乙烷引发。
- **监测**：由于格氏试剂显碱性，TLC点板可能拖尾，建议取少量样淬灭后点板。

### 底物兼容性
- **禁忌官能团**：禁止含有活泼氢（-OH, -NH, -SH, -C≡CH）、羰基（除非是反应位点）、环氧（通常开环）、硝基等。
- **特殊官能团**：卤素（Cl, Br, I）可能发生金属交换反应，需谨慎评估。

### 后处理要点
1.  **淬灭**：这是最关键的一步。必须**低温**、**慢滴**、**搅拌**，防止局部过热导致产物分解或溶剂沸腾。
2.  **乳化处理**：格氏反应后处理易乳化，可使用饱和NaCl溶液（盐析）或硅藻土过滤破乳。
3.  **干燥**：格氏反应后溶液通常含有大量镁盐，干燥时间需适当延长。

### 储存与稳定性
- 格氏试剂通常现配现用，或购买市售溶液（如THF溶液）。
- 储存于阴凉处，严格密封隔绝空气，避免使用塑料瓶塞（会腐蚀）。
