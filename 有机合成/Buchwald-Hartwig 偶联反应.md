# Buchwald-Hartwig 偶联反应操作指南（钯催化 C-N 胺化）

## 1. 试剂与仪器准备

### 常用试剂
- 芳基卤化物（Ar-X，X = Br, I, Cl；常用溴代物、碘代物）
- 胺类底物（一级胺、二级胺、芳胺、脂肪胺、酰胺等）
- 钯催化剂：
  - 常用：Pd₂(dba)₃、Pd(OAc)₂、Pd(dba)₂
- 配体（关键）：
  - 常用：BINAP、Xantphos、BrettPhos、RuPhos、DavePhos、JohnPhos、SPhos 等
- 碱：
  - 常用：NaOtBu、KOtBu、Cs₂CO₃、K₃PO₄、K₂CO₃ 等
- 溶剂：
  - 常用：甲苯、1,4-二氧六环、THF、DMF、DME 等
  - 需脱气处理（氮气鼓泡或冻融脱气）
- 干燥剂：无水 Na₂SO₄ 或 MgSO₄

### 仪器与装置
- 干燥反应管（带密封塞）或 Schlenk 瓶
- 磁力搅拌器、加热模块或油浴
- 惰性气体保护：高纯氮气或氩气（气球保护或 Schlenk 线）
- 冷凝管（回流时使用）
- 分液漏斗、旋转蒸发仪、色谱柱等后处理设备

## 2. 标准操作步骤（以芳基溴与一级胺偶联为例）

### 2.1 催化剂活化
1. 向干燥的反应管中加入 Pd₂(dba)₃（0.01–0.02 equiv，按 Pd 计 0.02–0.04 equiv）和配体（0.04–0.08 equiv，通常配体:Pd = 2:1 摩尔比）。
2. 加入少量脱气溶剂（如甲苯或 1,4-二氧六环，约 2 mL），在氮气/氩气保护下室温搅拌 5–10 分钟，使 Pd 与配体充分配位，体系颜色由深紫色变为橙色或红色。

### 2.2 加入底物与碱
3. 向活化后的催化剂溶液中依次加入芳基卤化物（1.0 equiv）、胺（1.2–1.5 equiv）和碱（1.2–2.0 equiv，常用 NaOtBu 或 Cs₂CO₃）。
4. 补加溶剂至底物浓度约 0.1–0.2 M，用氮气/氩气置换反应管 3 次，保持惰性气氛。
5. 若溶剂未预先脱气，可在置换后于氮气流下鼓泡脱气 5–10 分钟。

### 2.3 加热反应
6. 将反应管密封（或接冷凝管），置于预热至 80–110 °C 的油浴中搅拌。
   - 常用温度：80 °C（THF 体系）、100–110 °C（甲苯或二氧六环体系）。
7. 反应时间：通常 4–24 小时，TLC 或 GC/MS 监测原料消失。
   - 芳基碘代物反应较快（2–6 h），溴代物适中（6–12 h），氯代物较慢（12–24 h，需特殊配体如 BrettPhos、RuPhos）。

### 2.4 后处理
8. 反应完成后，冷却至室温。
9. 加入水稀释，用乙酸乙酯（或乙醚）萃取 2–3 次。
10. 合并有机相，依次用水、饱和食盐水洗涤。
11. 加入无水 Na₂SO₄ 或 MgSO₄ 干燥 30 分钟。
12. 过滤，减压浓缩，粗产物经柱层析（硅胶，常用石油醚/乙酸乙酯梯度洗脱，可加少量三乙胺抑制拖尾）或重结晶纯化。

## 3. 反应条件优化要点

### 3.1 配体选择（最关键）
- **芳基溴/碘 + 一级胺**：BINAP、Xantphos、DavePhos 等常用，催化效率高。
- **芳基氯 + 胺**：需使用富电子、大位阻配体，如 BrettPhos、RuPhos、XPhos，配合 Pd₂(dba)₃ 或 Pd(OAc)₂。
- **二级胺（如 N-甲基苯胺、吗啉）**：BrettPhos、RuPhos 效果最佳，可有效抑制 β-H 消除等副反应。
- **酰胺类底物**：Xantphos 表现优异，适合酰胺的 N-芳基化。

### 3.2 碱的选择
- 常用 NaOtBu（1.2–2.0 equiv），对多数芳基溴/碘反应高效，但强碱性可能对敏感底物不利。
- 对碱敏感底物（如含酯基、氰基）可选用 Cs₂CO₃ 或 K₃PO₄，碱性较弱但反应可能变慢。
- 芳基氯与脂肪胺偶联时常需 NaOtBu 或 KOtBu 强碱。

### 3.3 溶剂与脱气
- 溶剂需预先脱气，氧气会导致催化剂失活。
- 常用甲苯、1,4-二氧六环或 THF，根据底物溶解性和反应温度选择。
- 对极性底物可尝试 DMF 或 DME。

### 3.4 胺的当量与纯度
- 胺通常使用 1.2–1.5 当量。
- 液体胺应确保无水，必要时蒸馏或使用分子筛干燥。

### 3.5 温度与时间
- 标准温度 80–110 °C。
- 活性低的底物（如芳基氯、位阻大的胺）可提高温度至 120 °C（高压管）或延长反应时间。

## 4. 关键注意事项

### 4.1 无水无氧与惰性气氛
- 反应对氧气和水分敏感，需严格排除空气。
- 玻璃仪器应干燥，溶剂预先脱气。
- 反应全程保持氮气或氩气正压。

### 4.2 催化剂活化
- Pd₂(dba)₃ 与配体需预活化，否则游离的 dba 可能毒化催化剂。
- 使用 Pd(OAc)₂ 时，配体与 Pd 预混合后颜色变化是活化完成的标志。

### 4.3 底物兼容性
- 芳基卤化物可含：醚、缩醛、酰胺、酯（需碱强度匹配）、腈、氟、氯（可能竞争偶联，需选择合适条件）、三氟甲基等。
- 胺底物中避免含强配位基团（如游离 –SH、–COOH、–OH 通常可耐受但需注意碱的影响）。
- 含活泼氢的胺（如邻氨基苯酚）可能需要保护或优化条件。

### 4.4 后处理要点
- 钯残留：粗产物中可能含钯，必要时用活性炭吸附或硫醇树脂处理。
- 若使用 NaOtBu 等强碱，后处理时水洗可除去无机盐；必要时加少量稀酸中和。
- 若产物为碱性芳胺，柱层析时可在洗脱剂中加入 0.1–1% 三乙胺，防止拖尾。

### 4.5 反应监测
- 直接 TLC 检测通常可行。若胺底物无紫外吸收，可用碘缸显色或取少量反应液淬灭后 GC/MS 监测。

## 6. 安全提示

- 钯催化剂和配体可能对皮肤、呼吸道有刺激性，操作时佩戴手套和护目镜。
- NaOtBu、KOtBu 为强碱，遇水剧烈反应，取用时需在干燥环境中操作，避免接触皮肤。
- 有机溶剂（甲苯、二氧六环、DMF 等）易燃，加热时注意防火。
- 反应在密闭体系中进行时，确保密封管耐压，防止气体膨胀泄漏。
- 后处理加水时放热，应缓慢加入并搅拌。
