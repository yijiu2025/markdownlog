# 

> **说明**：四氧化锇（OsO₄）通常作为催化剂使用。根据共氧化剂（NMO 或 NaIO₄）的不同，反应结果截然不同：
> 1.  使用 **NMO**：发生**顺式二羟基化**，产物为邻二醇。
> 2.  使用 **NaIO₄**：发生**氧化裂解**（Lemieux-Johnson 反应），烯烃双键断裂，产物为醛或酮（若底物结构合适）。
>
> 以下文档涵盖了这两种主要反应类型。

---

## 1. 烯烃氧化裂解制备醛/酮（使用 NaIO₄）

此方法将烯烃双键彻底切断。若烯烃的一个取代基为烷基（R），裂解后该侧生成酮；若取代基为氢（H），则生成醛（通常会被进一步氧化为羧酸）。

### 方法A：一锅法裂解（Lemieux-Johnson 氧化）
- **投料当量**：
  - 底物（烯烃） : NaIO₄ : OsO₄ = 1 : 2.2-3.0 : 0.02-0.05
- **常用溶剂**：四氢呋喃/水（THF/H₂O = 2:1）、乙腈/水、或二氯甲烷/水
- **反应温度**：0°C 至 室温
- **反应时间**：2-12 小时
- **注意事项**：
  - **剧烈搅拌**：NaIO₄ 在水中溶解度较小，需剧烈搅拌保证两相接触。
  - **底物限制**：端基烯烃（R-CH=CH₂）裂解后生成甲醛，迅速氧化为甲酸；另一侧生成醛/酸。只有当双键碳上连有两个烷基时，才能生成酮。
  - **OsO₄用量**：OsO₄ 极毒且昂贵，通常仅需催化量（2-5 mol%）。
- **后处理**：
  - 反应液中加入饱和 Na₂S₂O₃ 溶液（以还原残留的 OsO₄）。
  - 过滤除去不溶性的碘酸盐（NaIO₃）及其他固体杂质。
  - 滤液用二氯甲烷（DCM）或乙酸乙酯（EA）萃取。
  - 有机相用饱和 NaHCO₃、盐水洗涤，无水 Na₂SO₄干燥，浓缩纯化。

### 方法B：两步法（先二羟基化，后裂解）
适用于复杂底物，旨在控制反应进程或避免副反应。
1.  **第一步**：使用 OsO₄/NMO 进行顺式二羟基化（见第2部分），分离得到二醇中间体。
2.  **第二步**：溶解二醇于 THF/H₂O 中，加入 NaIO₄（2.2 eq），室温裂解。

---

## 2. 烯烃顺式二羟基化（使用 NMO）

此方法在双键上顺式添加两个羟基，生成邻二醇。**注意：产物不是酮。**

### 方法A：Upjohn 二羟基化（标准法）
- **投料当量**：
  - 底物（烯烃） : NMO : OsO₄ = 1 : 1.2-2.0 : 0.01-0.02
- **常用溶剂**：丙酮/水（9:1）、四氢呋喃（THF）
- **常用试剂**：NMO（一水合物或无水粉末）
- **反应温度**：0°C 至 室温
- **反应时间**：4-24 小时
- **注意事项**：
  - **立体选择性**：专一性顺式加成（Syn-addition）。
  - **配体**：对于手性烯烃，可加入手性配体（如 DHQD）实现不对称双羟基化（AD反应）。
  - **避免过度氧化**：NMO 是温和的共氧化剂，相比 NaIO₄，不会切断双键。
- **后处理**：
  - 加入饱和 Na₂S₂O₃ 溶液淬灭。
  - 若有固体析出，过滤。
  - 用 EA 或 DCM 萃取，水洗，干燥，浓缩。二醇极性大，通常需要柱层析（DCM/MeOH）纯化。

---

## 3. 通用注意事项（极重要）

### 安全警示（OsO₄）
- **剧毒性**：四氧化锇挥发性和穿透力极强，对眼睛、角膜有不可逆的灼伤伤害（可能导致失明），对呼吸道有严重腐蚀性。
- **操作要求**：
  - 必须在高效通风橱内操作。
  - 必须佩戴防化学护目镜、丁腈手套（建议双层）和实验服。
  - 称量时需极其小心，建议使用预制备好的稀溶液（如 2.5% in t-BuOH）以减少固体挥发风险。

### 反应监控
- **TLC监测**：由于 OsO₄ 深紫色，反应液通常呈黑色或褐色，点板时难以观察。需取少量样用 Na₂S₂O₃ 或 PPh₃ 还原褪色后点板。
- **现象**：使用 NaIO₄ 时，溶液中会有大量白色固体（NaIO₃）生成。

### 废物处理
- **含锇废液**：严禁直接倒入下水道。需收集在专用废液桶中，通常加入大量植物油或酒精还原后作为危险废物处理。
- **清洗**：玻璃器皿需用含还原剂（如洗洁精+亚硫酸钠或乙醇）的溶液清洗，以去除残留的 OsO₄。

## 4. 示例投料表（以氧化裂解制备酮为例）

| 试剂             | 当量  | 质量/体积计算示例（以1 mmol底物计）                   |
| -------------- | --- | ------------------------------------------ |
| 底物（环己烯）      | 1.0 | 82 mg                                       |
| NaIO₄（高碘酸钠）   | 2.5 | 535 mg                                       |
| OsO₄（4% in t-BuOH） | 0.02 | ~100 μL（约 0.02 mmol，催化剂）                     |
| THF / H₂O (2:1) | -   | 5 mL THF + 2.5 mL H₂O                       |
| 饱和 Na₂S₂O₃    | -   | 5 mL（淬灭用）                                  |

---

> **注意**：使用 **NaIO₄** 是制备酮（通过双键断裂）的方法；使用 **NMO** 是制备邻二醇的方法。请根据目标产物选择正确的共氧化剂。首次尝试务必小量摸索，并做好严密的安全防护。
